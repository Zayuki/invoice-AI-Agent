# Invoice Agent (POC)

Telegram bot that generates invoices via chat. Owner reviews before send.

## Stack (fixed — do not substitute)
- FastAPI (Python 3.12), backend only
- Telegram Bot API via webhook
- LLM: OpenAI Codex for chat → structured invoice extraction

## Rules
- Mobile-first: bot replies must be short, few taps, no wide tables.
- Nothing sends to a client until the owner approves in Telegram.
- POC: no auth system, no multi-tenant, no payment integration.
